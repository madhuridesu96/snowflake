# snowflake
Snowflake keeps data (storage) and processing power (compute) separate. All table data is stored once in a central place, and virtual warehouses are independent engines that read from that shared storage when a query runs. Because each warehouse has its own CPU and memory, two people can query the same table at the same time, for example one on an XSMALL warehouse and another on a LARGE warehouse, without slowing each other down. They read the same data but do the work on separate compute, so there is no competition for resources. This also means storage and compute can be scaled and paid for separately: you only pay for compute while a warehouse is running.
